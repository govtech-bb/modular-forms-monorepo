# Form Builder App — Design Spec

**Date:** 2026-05-19  
**Branch:** platform/registry-builder  
**Status:** Approved

## Overview

Extract the form builder UI from `apps/web` into its own standalone `apps/form_builder` app. The builder currently lives as a `/builder` route inside the citizen-facing renderer (`apps/web`). After this change, `apps/form_builder` is an independent Vite + React 19 + TanStack Router application, and the `/builder` route is removed from `apps/web` entirely.

## Approach

**Lean standalone app** — scaffold `apps/form_builder` with only the dependencies the builder actually uses (React, TanStack Router, `@govtech-bb/form-builder`, `@govtech-bb/form-types`). No renderer baggage (`@tanstack/react-form`, `zod`, `uuid`, etc.).

Nx auto-discovers `apps/form_builder` via the `apps/*` workspace glob. The `project.json` registers the project name `form-builder` and its targets.
